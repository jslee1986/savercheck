# 세이버체크 — 지금 쿠팡이 제일 싼 상품

쿠팡 가격을 같은 시점의 대형몰(11번가·G마켓·옥션·SSG·롯데ON·하이마트·홈쇼핑 등) 일반가와 비교해,
쿠팡이 더 싼 상품만 내 쿠팡 파트너스 링크로 보여주는 사이트입니다.

## 자동 운영
| 시각 (한국) | 작업 | 실행 주체 |
|---|---|---|
| 매시 10분 | 쿠팡 가격 확인(골드박스 + 관심 키워드) → 기록 → 특가 판정 → 사이트 갱신 | GitHub Actions |
| 07:40 | 골드박스 갱신 직후 추가 확인 | GitHub Actions |
| 하루 5번 | 다나와로 다른 대형몰 가격 비교 → `data/compare.json` push → 사이트 자동 갱신 | Claude 예약 작업 (`CLAUDE_TASK.md`) |

## 판정 규칙
- 특가 등록: 쿠팡 일반가 < 같은 시점 대형몰 일반가(배송비 포함) 최저. 카드·회원가는 표시만 하고 판정에 안 씀
- 같은 상품인지: 모델명 → 색상·연식(신형) → 용량·수량 → 상품명 겹침 순으로 확인, 확신 낮으면 비교 제외
- 가격 오류 의심(다른 대형몰 중간값의 85% 미만)과 소형몰은 제외
- 배지: 현재 비교몰 최저가 / 관측 이래 최저가 / 최근 60일 최저가(60일 이상 기록 시) / 평균보다 20% 저렴 / 기록 수집 중(14일 미만)
- 특가 종료: 가격 인상·쿠팡 목록에서 사라짐·비교 만료 시 사유와 함께 종료 표시
- 오래된 가격(쿠팡 3시간, 타몰 8시간 초과)은 특가 판정에서 제외, 상단에 마지막 확인 시각 표시
- 같은 상품은 `p/쿠팡상품ID.html` 한 페이지를 계속 갱신 (중복 생성 없음)
- 3만원 미만 상품 제외 (`common.py`의 MIN_PRICE)

## 데이터 (`data/`)
- `observations.csv` 가격 관측 기록: 확인 시각·상품·판매처·구성·가격·배송비·합계·카드가·회원가·조건·출처
- `products.json` 상품 상태, `coupang.json` 최근 쿠팡 확인 결과, `compare.json` 타몰 비교, `deals.json` 특가 시작·종료

## 설정
- Secrets: `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` (쿠팡 파트너스 → 추가기능 → Open API)
- Variables(선택): `SITE_URL` (도메인 연결 시)
- `watchlist.txt`: 매일 추적할 관심 상품 키워드 (최대 10개)
